    📘 Python 数据读写¶

    核心库说明：

    • Pandas: 处理结构化数据（表格）的神器，90%的情况都用它。
    • Numpy: 处理纯数值矩阵，适合后续的算法计算。
    • Pickle: Python自带库，用于保存“半成品”数据（如训练好的模型、清洗后的数据列表）。

    1. 核心：Pandas 读取数据 (CSV/TXT)¶

    美赛最常见的数据格式是 .csv 或 .txt。pd.read_csv 是最通用的函数。

    import pandas as pd

# 基础读取
df = pd.read_csv('data.csv')

# 🚩 进阶场景（美赛高频痛点解决方案）
df = pd.read_csv(
    'data.csv', 
    sep=',',                  # 分隔符。TXT文件若是空格分隔，用 sep='\s+'
    header=0,                 # 指定哪一行是表头，默认为0。若无表头，设为 None
    names=['Col1', 'Col2'],   # 如果没有表头，可以在这里自定义列名
    index_col=0,              # 将第0列作为索引（不再是0,1,2...）
    encoding='utf-8',         # 编码格式。若报错，尝试 'gbk' 或 'ISO-8859-1'
    na_values=['?', 'NA', '-'] # 将这些特殊符号统一识别为 NaN（缺失值）
)

# ⚡ 技巧：处理超大文件（分块读取）
# 如果数据有几GB，一次性读入会爆内存
chunk_size = 10000
for chunk in pd.read_csv('big_data.csv', chunk_size=chunk_size):
    # 在这里对每一块数据(chunk)进行处理
    process(chunk)

    2. 处理 Excel 文件 (.xlsx / .xls)¶

    Excel文件读取较慢，建议读取一次后转存为CSV或Pickle以便后续快速加载。

    # 需要安装依赖: pip install openpyxl

# 读取特定 Sheet
df_sheet1 = pd.read_excel('data.xlsx', sheet_name='Sheet1')

# 读取所有 Sheet (返回一个字典)
all_sheets = pd.read_excel('data.xlsx', sheet_name=None)
# all_sheets['Sheet1'] 即为对应的 DataFrame

    3. 非结构化数据读取 (TXT/Log)¶

    当数据不是标准的行列格式（例如复杂的日志文件、文本段落）时，使用原生 Python 方法。

    # 读取所有行到一个列表
with open('data.txt', 'r', encoding='utf-8') as f:
    lines = f.readlines()

# 逐行处理（去除换行符，分割数据）
clean_data = []
for line in lines:
    row = line.strip().split() # 默认按空白符分割
    clean_data.append(row)

# 转为 DataFrame
df = pd.DataFrame(clean_data)

    4. 数据的导出 (Writing)¶

    建模结束后，需要将结果导出放到论文附录或提交文件中。

    # 导出为 CSV
# index=False 非常重要！否则会多出一列 0,1,2... 的索引列
df.to_csv('result.csv', index=False, encoding='utf-8-sig') 
# 注意：'utf-8-sig' 可以解决 Excel 打开 CSV 中文乱码的问题

# 导出为 Excel
df.to_excel('result.xlsx', sheet_name='Result', index=False)

    5. 极速读写中间结果 (Pickle)¶

    场景： 数据清洗花了1个小时，或者模型训练了30分钟。一定要把结果存下来，防止程序崩溃重跑。Pickle 读写速度极快，且保留所有数据类型（不用重新解析日期、数字）。

    import pandas as pd

# 1. 保存 DataFrame 到 pickle
df.to_pickle('clean_data.pkl')

# 2. 只有 Python 能读回来的极速加载
df_load = pd.read_pickle('clean_data.pkl')

    6. Numpy 矩阵读写¶

    如果你的数据全是数字，且不需要列名（主要用于算法输入），Numpy 更纯粹。

    import numpy as np

# 读取文本矩阵
# delimiter: 分隔符
matrix = np.loadtxt('matrix_data.txt', delimiter=',') 

# 保存矩阵
np.savetxt('output_matrix.txt', matrix, fmt='%.4f', delimiter=',') 
# fmt='%.4f' 保留4位小数

    ⚡ 避坑指南 (Troubleshooting)¶

    1. FileNotFoundError:

    2. 原因: 路径不对。

    3. 解决: 使用相对路径（把数据文件和代码放在同一文件夹）；或者在代码最前面加：

      import os
print(os.getcwd()) # 查看当前工作目录

    4. UnicodeDecodeError:

    5. 原因: 编码不匹配。

    6. 解决: 只要报错，就轮流换 encoding='utf-8', encoding='gbk', encoding='gb18030'。

    7. ParserError:

    8. 原因: CSV中某一行数据多了个逗号，导致列数对不上。

    9. 解决: 使用 error_bad_lines=False (旧版Pandas) 或 on_bad_lines='skip' (新版Pandas) 跳过错误行。

    🧹 缺失值处理¶

    核心原则： 1. 不要轻易删除：除非缺失比例极高（>50%）或者该样本完全不可用，否则尽量保留数据。 2. 分情况讨论：时间序列缺了用插值，分类数据缺了用众数，数值数据缺了用均值/中位数/KNN。 3. 在论文中写明：一定要在论文的 Data Preprocessing 章节说明你用了什么方法填补，这体现了严谨性。

    1. 侦察：快速发现缺失值¶

    在动手处理前，先看缺了多少，缺在哪里。

    import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

# 假设 df 是你的数据框
# df = pd.read_csv('data.csv')

# 🔍 方法 1: 统计每列缺失值的数量（最常用）
print(df.isnull().sum()) 

# 🔍 方法 2: 查看缺失比例（百分比）
missing_rate = df.isnull().sum() / len(df) * 100
print(missing_rate[missing_rate > 0]) # 只看有缺失的列

# 🔍 方法 3: 可视化缺失分布（写论文放图很好用）
plt.figure(figsize=(10, 6))
sns.heatmap(df.isnull(), cbar=False, cmap='viridis')
plt.title("Missing Data Visualization")
plt.show()
# 亮色部分代表缺失，可以看出缺失是集中在某几行，还是随机分布

    2. 策略一：直接删除 (Deletion)¶

    适用场景： 缺失值极少（例如 10000 行里只有 5 行缺了），或者某列缺失率高达 80% 以上（直接废弃该特征）。

    # 1. 删除包含任何缺失值的行（慎用，容易把数据删光）
df_dropped = df.dropna(how='any')

# 2. 仅当某一行【全部】为空时才删除
df_dropped = df.dropna(how='all')

# 3. 阈值删除：如果非空值少于 n 个，则删除该行
# 例如：一行有 10 个特征，至少要有 8 个非空数据才保留
df_dropped = df.dropna(thresh=8)

# 4. 删除某一列（如果该列 90% 都是空的）
df_dropped = df.drop(columns=['Bad_Column'])

    3. 策略二：统计值填充 (Simple Imputation)¶

    适用场景： 数据服从某种分布，且缺失是随机的。

    # 1. 用均值填充 (适合正态分布的数据)
df['Age'] = df['Age'].fillna(df['Age'].mean())

# 2. 用中位数填充 (适合有离群值/偏态分布的数据，如收入、房价)
df['Salary'] = df['Salary'].fillna(df['Salary'].median())

# 3. 用众数填充 (适合分类变量，如性别、地区)
# mode() 返回的是 Series，所以要取 [0]
df['Gender'] = df['Gender'].fillna(df['Gender'].mode()[0])

# 4. 用固定值填充
df['Score'] = df['Score'].fillna(0) # 比如缺失代表没参加考试，记为0

    4. 策略三：时间序列插值 (Interpolation) 🔥美赛高频¶

    适用场景： 数据是随时间变化的（如气温、股票、人口增长）。千万不要用均值填时间序列！ 昨天的温度和明天的温度对今天最有参考价值。

    4.1 基础填充 (Padding)¶

    适用于离散变化或不需要平滑曲线的场景。

    # 1. 前向/后向填充 (常用在股票/金融，假设价格保持不变直到下一次变动)
df['Stock'] = df['Stock'].fillna(method='ffill') # 用前一个填
df['Stock'] = df['Stock'].fillna(method='bfill') # 用后一个填

    4.2 数学插值 (Mathematical Interpolation) 🌟¶

    当数据代表连续变化的物理量（如速度、温度、生长曲线）时，使用数学函数拟合效果更好。

    方法 说明 适用场景 论文理由 (Keywords)
    Linear (线性) 连接两点的直线 数据点之间关系比较简单且变化较平稳的情况 Simple, Conservative approximation
    Polynomial (多项式) 用曲线连接 (2次/3次) 数据点数比较少且希望插值函数平滑通过所有数据点的情况 Capture non-linear trends
    Cubic Spline (三次样条) 最推荐，保证曲线光滑 数据点较多且分布不均匀的情况 Smoothness, Continuity, Physics-informed 
    # 假设 df['Value'] 是需要填充的列

# 1. 线性插值 (Linear) - 最安全，最常用
# 就像在两点之间拉一根直线
df['Value_Linear'] = df['Value'].interpolate(method='linear')

# 2. 多项式插值 (Polynomial) - 能够拟合抛物线等形状
# order=2 代表二次函数。注意：若数据波动大，高阶多项式会在边缘产生剧烈震荡(Runge现象)，慎用 > 3
df['Value_Poly'] = df['Value'].interpolate(method='polynomial', order=2)

# 3. 三次样条插值 (Cubic Spline) - 论文加分项 🔥
# 能够生成非常平滑的曲线，适合模拟自然界的连续变化
# 注意：需要安装 scipy (pip install scipy)
df['Value_Spline'] = df['Value'].interpolate(method='cubicspline')
# 或者使用 method='spline', order=3

    5. 策略四：算法模型填充 (Advanced Imputation) 🔥加分项¶

    适用场景： 多维数据，且希望利用其他列的信息来预测缺失列。这比单纯用均值更精准。

    5.1 KNN 填充 (最近邻)¶

    原理：找和当前样本最像的 K 个样本，用它们的均值来填。

    from sklearn.impute import KNNImputer

# 注意：KNN 只能处理数值型数据
imputer = KNNImputer(n_neighbors=5) # 找最近的5个邻居

# fit_transform 返回的是 numpy 数组，需要转回 DataFrame
df_filled_array = imputer.fit_transform(df[['Col1', 'Col2', 'Col3']])
df_filled = pd.DataFrame(df_filled_array, columns=['Col1', 'Col2', 'Col3'])

    5.2 随机森林填充 (极高精度)¶

    原理：把缺失列作为标签(Target)，其他列作为特征，训练一个模型去预测缺失值。 代码略繁琐，美赛时间紧迫时优先推荐 KNN。

    ⚡ 避坑指南 & 论文写作话术¶

    1. 数据类型坑：
    2. 在填充前，确保你的数值列真的是数值类型。如果读取进来是 Object (字符串)，mean() 会报错。

    3. 检查代码：df.dtypes。如有必要先转类型：pd.to_numeric(df['col'], errors='coerce')。

    4. 填充顺序：

    5. 先分训练集和测试集，再计算均值填充？(机器学习严格要求这样，防止数据泄露)。

    6. 美赛特例：美赛通常是做描述性统计或整体建模，可以直接对整个数据集进行填充，这在美赛中通常是可以接受的。

    7. 论文里怎么吹？(Copy 到论文中)

      "Data preprocessing is a crucial step for model robustness. For missing values in the dataset, we analyzed the missing mechanism. For continuous variables with random missingness, we employed K-Nearest Neighbors (KNN) imputation to preserve the local structure of the data. For time-series data, cubic spline interpolation was applied to maintain temporal continuity." (数据预处理对模型的鲁棒性至关重要。针对数据集中的缺失值，我们分析了其缺失机制。对于随机缺失的连续变量，我们采用了 KNN 插值法 以保留数据的局部结构；对于时间序列数据，则应用了**三次样条插值**以保持时间上的连续性。)

    📅重采样¶

    特性 🧹 缺失值处理 📅 重采样 (Resampling)
    核心定义 处理原始数据中本身就缺漏的部分 (NaN) 改变时间序列数据的频率 (高频↔低频)
    数据行数 保持不变 (或减少) 必然改变 (增加或减少)
    典型方法 均值、中位数、KNN、插值 聚合(Sum/Mean)、AsFreq
    是否产生 NaN 目标是消灭 NaN 升采样会**制造** NaN，降采样会**消灭** NaN
    适用范围 任何数据 (分类/数值/时间) 仅限时间序列数据

p_coeffs = np.polyfit(x, y, 3) # 3次多项式系数

    🛡️异常值检测与处理 (Outlier Detection)¶

    为什么要做这一步？ 异常值（Outliers）是偏离大部分样本极远的数据点（如某人身高 3 米，或某天销量为负数）。如果不处理，它们会严重拉偏均值，导致线性回归、神经网络等模型失效。

    🔍 美赛进阶笔记：统计 vs 聚类 异常检测 (Advanced Outlier Detection)¶

    在美赛建模中，选择哪种异常检测方法，取决于你的**数据维度**和**分布形态**。

    维度 基于统计的异常检测 (Statistical-based) 基于聚类的异常检测 (Clustering-based)
    核心含义 假设数据服从某种分布（如正态分布）。
    利用**均值、标准差**等指标，找出显著偏离大多数的数据点。    		 利用聚类算法（如 K-means, DBSCAN）。
    将数据分组，**远离簇中心**或处于**低密度区域**的点被视为异常。
    操作步骤 1. 计算指标：算均值(\(\mu\))、标准差(\(\sigma\))。
    2. 确定阈值：如 \(3\sigma\) 原则。
    3. 识别异常：超过阈值即标记。    		 1. 聚类：运行聚类算法。
    2. 算距离/密度：计算点到簇中心的距离或所在区域密度。
    3. 确定阈值：设定距离阈值。
    4. 识别异常：筛选出离群点。
    ✅ 优点 简单易懂，计算速度快。
    对已知分布（如正态分布）的数据效果极好。    		 不依赖统计分布，适用于复杂数据集。
    适用于**多模态**（多波峰）和**高维数据**。
    ❌ 缺点 对非正态分布或多模态数据效果较差。
    难处理高维数据（维度灾难）。    		 算法选择和参数（如K值、半径）对结果影响大。
    计算复杂度较高（跑得慢）。

    单变量 + 钟形曲线（如某地气温、学生成绩）：

    • 👉 选 3σ原则 (统计)。简单，评委一看就懂。

    单变量 + 分布未知/偏态（如人均收入）：

    • 👉 选 箱线图 IQR (统计)。最稳妥，不易出错。

    多变量 + 找离群个体（如根据“身高+体重+心率”找身体异常的人）：

    • 👉 选 孤立森林 (Isolation Forest) 或 DBSCAN (聚类)。

    1. 侦察：如何揪出异常值？¶

    方法一：3σ 原则 (Z-Score)¶

    适用场景：数据近似**正态分布**（如身高、考试成绩、测量误差）。 原理：超过 均值 ± 3倍标准差 的数据视为异常。

    import pandas as pd
import numpy as np
from scipy import stats

# 模拟数据
data = pd.DataFrame({'Value': np.random.normal(0, 1, 1000)})
# 人为制造一个异常值
data.loc[0, 'Value'] = 10 

# 计算 Z-score
z_scores = np.abs(stats.zscore(data['Value']))

# 找出异常值索引 (Z-score > 3)
outliers = data[z_scores > 3]
print(f"发现 {len(outliers)} 个异常点")

    方法二：IQR 箱线图法 (Interquartile Range) 🔥 美赛最推荐¶

    适用场景：数据分布未知，或者偏态分布（如收入、房价）。这也是Boxplot画图背后的逻辑。

    原理：利用四分位数。

    • 下界 = \(Q1 - 1.5 \times IQR\)
    • 上界 = \(Q3 + 1.5 \times IQR\)
    Q1 = df['Col'].quantile(0.25)
Q3 = df['Col'].quantile(0.75)
IQR = Q3 - Q1

lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR

# 筛选出异常值
outliers = df[(df['Col'] < lower_bound) | (df['Col'] > upper_bound)]
print("异常值范围:", lower_bound, "~", upper_bound)

    方法三：孤立森林 (Isolation Forest) 🤖 机器学习加分项¶

    适用场景：多维数据（例如，身高1.7米正常，体重50kg正常，但身高1.7米且体重50kg在相扑运动员数据集中可能就是异常）。

    原理：把数据随机切分，容易被切分开（孤立）的点就是异常点。

    from sklearn.ensemble import IsolationForest

# contamination: 预计异常值的比例，比如 5%
clf = IsolationForest(contamination=0.05, random_state=42)

# 训练并预测 (-1 表示异常, 1 表示正常)
df['Is_Outlier'] = clf.fit_predict(df[['Col1', 'Col2']])

# 查看异常数据
outliers = df[df['Is_Outlier'] == -1]

    2. 处理：发现异常值后怎么办？¶

    策略一：删除 (Drop)¶

    最简单粗暴。如果异常值确实是记录错误（如年龄 -5 岁），直接删。

    # 结合上面的 IQR 方法
clean_df = df[(df['Col'] >= lower_bound) & (df['Col'] <= upper_bound)]

    策略二：盖帽法 (Winsorization / Capping) 🔥 推荐¶

    不删除数据，而是把太大的数变成“最大允许值”，太小的数变成“最小允许值”。保持样本量不变。

    # 将所有小于下界的值设为下界，大于上界的值设为上界
df['Col_Capped'] = df['Col'].clip(lower=lower_bound, upper=upper_bound)

    策略三：对数变换 (Log Transformation)¶

    适用场景：数据跨度极大（如收入、人口、点击量）。取对数可以将长尾分布拉回正态分布，减弱极端值的影响。

    # 使用 log1p (log(x+1)) 避免 x=0 时报错
df['Log_Income'] = np.log1p(df['Income'])

    补充方法：标记异常值，后续分类处理

    ⚡ 补充：关于“空白值”的快速回顾¶

    由于上一份笔记已详细讲解缺失值，这里给出一个**极简的综合处理代码块**（Blank + Outlier 一条龙），适合比赛时直接调用：

    def auto_clean(df, col_name):
    """
    自动处理某列的缺失值和异常值
    1. 缺失值：用中位数填充
    2. 异常值：用盖帽法处理 (IQR)
    """
    # 1. 填补缺失值
    median_val = df[col_name].median()
    df[col_name] = df[col_name].fillna(median_val)

    # 2. 计算 IQR 边界
    Q1 = df[col_name].quantile(0.25)
    Q3 = df[col_name].quantile(0.75)
    IQR = Q3 - Q1
    lower = Q1 - 1.5 * IQR
    upper = Q3 + 1.5 * IQR

    # 3. 盖帽法处理异常值
    df[col_name] = df[col_name].clip(lower=lower, upper=upper)

    return df
